# MVP features

| # | Feature | Sprint |
|---|---|---|
| 1 | Register, log in, log out, auto-login (Firebase Authentication) | Sprint 1 (Lab 1) |
| 2 | List my workouts | Sprint 1 (Lab 2) |
| 3 | Add, edit and delete a workout (detail/edit screen) | Sprint 1 (Lab 2) |
| 4 | Weekly stats calculated by a Cloud Function | Later (Lab 3) |
| 5 | Find a partner: create and join training sessions | Later |

## Limits from the course
- Maximum 5 screens, including login and register.
- Maximum 3 Firestore collections.
- At least one feature that needs server-side logic or file storage (Lab 3): weekly stats Cloud Function.

## Screens (5)
Login · Register · Workouts (home list) · Workout detail/edit · Partners (training sessions).
